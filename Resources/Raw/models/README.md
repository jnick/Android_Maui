# Модели компьютерного зрения

Все файлы `.onnx` получены из репозитория [OpenCV Zoo](https://github.com/opencv/opencv_zoo)
и лежат здесь как обычные файлы, включённые в приложение через `MauiAsset`
(в Android-сборке они попадают в `assets/models/`, в Windows — рядом с исполняемым файлом).

## Откуда брать

Обычная ссылка `raw.githubusercontent.com` на эти файлы **не работает**: репозиторий
хранит модели в Git LFS, и по обычной ссылке отдаётся файл-заглушка размером 131 байт.
Рабочая ссылка — домен `media.githubusercontent.com`:

```
https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/<путь-к-файлу>
```

## Лицензии

Требуется сохранять уведомление об авторских правах при использовании, поэтому
файл `LICENSE` каждого семейства из зоопарка продублирован здесь. Файлы лежат
рядом с моделями и потому попадают в сборку приложения вместе с ними:

| Файл здесь | Оригинал в зоопарке | Лицензия |
|---|---|---|
| `LICENSE-yunet` | `models/face_detection_yunet/LICENSE` | MIT |
| `LICENSE-nanodet` | `models/object_detection_nanodet/LICENSE` | Apache-2.0 |
| `LICENSE-yolox` | `models/object_detection_yolox/LICENSE` | Apache-2.0 |

Код самих моделей (декод выходов, NMS, препроцессинг) написан в этом проекте
в `Services/Detection/Models/` и распространяется вместе с исходниками приложения.

## Важное предупреждение про эталонный код зоопарка

Эталонные примеры зоопарка (`yunet.py`, `nanodet.py`, `yolox.py`) **не соответствуют
текущим файлам моделей**, и копировать их декод нельзя. Это проверено разбором
сигнатур моделей:

* `yunet.py` ожидает один выход формы `1×15×N`, а файл 2023 года отдаёт **12 выходов**
  (`cls`, `obj`, `bbox`, `kps` на трёх масштабах) и принимает вход строго 640×640;
* `nanodet.py` рассчитан на 4 масштаба и разбирает выходы как `preds[::2]` / `preds[1::2]`,
  а файл 2022 года отдаёт **3** пары выходов в порядке
  `cls8, cls16, cls32, bbox8, bbox16, bbox32` — срез `preds[::2]` перемешивает их;
* `yolox.py` актуален: вход `1×3×640×640`, выход `1×8400×85`, 8400 = 80² + 40² + 20².

Декод для каждой модели в этом проекте восстановлен по реальным выходам сети
и проверен численно — подробности в комментариях у `Services/Detection/Models/*.cs`.
Для YuNet результат дополнительно сверен с эталонной реализацией
`cv2.FaceDetectorYN` (совпадение IoU = 1,000).
